# Omni UGV

KiCad design, revision history, and engineering work for a miniature three-wheel omnidirectional camera rover.

The latest power-routing candidate is under [Rev F power rebuild](outputs/rover/Omni_UGV_Rev_F_power_rebuild/START_HERE.md). This revision is a work in progress. Its saved DRC report lists 19 open connections and 7 dangling traces. Hold fabrication until the routing and power review are complete.

Earlier board revisions, review packages, and development scripts are included for reference.
