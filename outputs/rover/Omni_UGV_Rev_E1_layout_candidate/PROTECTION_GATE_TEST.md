# Battery startup and held-fault bench gate

2026-11-09 · **BLOCKED · Awaiting physical measurements**

This test qualifies the proposed MAX17301/BQ24074/Q13 interface before routing it into the rover. It can run on evaluation hardware with the intended Q13 branch replicated. It does not require a rover PCB. Use `PROTECTION_GATE_RESULTS.csv` to record the cases. All cases are currently NOT RUN.

## Fixture

- Use the MAX17301G evaluation kit or a documented equivalent, a BQ24074 evaluation board, and a breakout for the Rev E Q13 circuit. Record exact board variants, shunt value, gate-drive configuration, and actual off-state diode direction. The TI evaluation board ships with a 0.9 A charge setting. Match Rev E's 3.57 kΩ ISET and applicable input-current settings before drawing rover conclusions. Set charger temperature inputs to a valid room-temperature equivalent for the cell simulator. [ADI evaluation kit guide](https://www.analog.com/media/en/technical-documentation/data-sheets/max17300gevkit-max17313xevkit.pdf) · [TI BQ24074 evaluation board](https://www.ti.com/tool/BQ24074EVM)
- Use a floating, current-limited, source/sink battery simulator and differential probes. Cell simulator terminals go to BATT+/BATT−. The charger BAT path goes through the replicated Q13 branch to PCKP, with charger ground on the system side of the shunt. Connect the load at the tested node relative to the system side of the shunt. Check every ground and USB instrument connection for a shunt bypass before enabling power. Disconnect the programming interface during cold-start tests so communications cannot wake the protector.
- Start with no LiPo, no motors, and a low-energy, current-limited test profile. Have the lab operator verify the simulator and lead transient behavior. ADI cautions that supply and lead inductance can cause overshoot during high-current FET switching. A lower trip setting can screen the state transitions, provided the run records it and reproduces the intended fault status. A lab-qualified high-current setup is required to establish the final 12 A candidate setting, trip energy, or thermal performance. [ADI evaluation kit guide, Troubleshooting](https://www.analog.com/media/en/technical-documentation/data-sheets/max17300gevkit-max17313xevkit.pdf)
- Verify readback of the exact configuration after reset before testing. Record DevName, PBen, COMMSH, UV and shutdown settings, charge and discharge limits, fault delays, and the shunt value. Use the qualified lab profile for screening. Do not copy preliminary settings to production NVM.

## Evidence and decisions

Record cell terminal voltage, PCKP, charger BAT/VBAT, USB VBUS, CHG and DIS gate-to-source voltages, Q13 gate-to-source voltage, and cell current with sign. Save fault status before and after each applied fault. Use repeatable pulse or electronic-load fixtures whose current, energy and transient behavior are bounded by the lab setup. First verify short and overcurrent status separately with USB absent. Confirm the intended comparator tripped before interpreting a recovery result.

1. **Cold startup.** At 4.20 V and 3.10 V, repeat true power removal/insertion three times with USB and the programmer disconnected. Confirm that if the protector does not already start, one valid wake-button press makes it support a 50 mA test load with PCKP within 100 mV of the cell within 2 s after the wake input is accepted. These are engineering screening targets. Capture wake debounce separately and repeat cold insertion with charger USB already attached.
2. **Held fault.** For both the actual PCKP node and downstream VBAT, record the trip followed by 60 s of held fault. Test USB absent, already attached, and attached after the trip. Include Q13 on and off as relevant and repeat with a wake button press while faulted. Pass only if the charger or wake button causes no unwanted discharge-FET re-enable or cell discharge pulse into the held fault. Log transient acquisition settings and current resolution. A rise at PCKP alone does not establish re-enable. Compare gate drive and signed cell current.
3. **Fault removed.** Open the imposed load while watching PCKP, DIS and cell current. Verify that the recovered path supports the 50 mA test load. Test intermediate residual resistance as a sensitivity exercise. A 1 kΩ load needs only 1 mA total to reach the nominal 1 V release threshold. That resistor by itself cannot exercise a high-current trip.
4. **Undervoltage.** Use the simulator to cross the configured UV and UV-shutdown thresholds. Confirm battery-only wake does not resume discharge while UV persists. Then attach charger USB and verify bounded recovery through the intended path once the simulator permits recovery. Observe charger BAT cycling and Q13 state. Charger current and voltage must stay within the test fixture limits. This case is separate from a held discharge fault.

The gate passes only after all applicable rows have signed waveform and configuration evidence with no unsafe discharge retry. A changed charger path or protector profile requires a new run. A failure sends the circuit back to design for charger isolation or a different protection architecture. Once integrated, the first rover PCB also needs its own USB motor-inhibit, full-current, thermal, and cell-probe tests.
